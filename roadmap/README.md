# Bus Booking System — Learning Roadmap

## Overview

This repository contains a progressively developed full-stack Bus Booking application. The goal is to learn web development by building one cohesive application, rather than creating disconnected demonstrations of individual technologies.

The project will evolve from a static HTML, CSS, and JavaScript application into a complete system using Angular, Node.js, Express, and MongoDB.

Throughout the process, each feature will build on previous work and demonstrate how the frontend, backend, authentication, state management, database, APIs, and user interface work together.

## Technology Stack

- **Initial frontend:** HTML, CSS, JavaScript
- **Frontend framework:** Angular
- **Backend:** Node.js and Express
- **Database:** MongoDB
- **Authentication:** Google authentication
- **Additional features:** Dark mode and internationalization (i18n)

## Learning Method

This project follows a question-driven learning approach.

1. Read the current question and understand its requirements.
2. Attempt the implementation independently.
3. Test the feature and investigate edge cases.
4. Understand the design decisions and how the feature interacts with existing components.
5. Refactor when necessary and commit meaningful progress to GitHub.
6. Record completed questions, unresolved issues, and the next learning target.

AI assistance may be used when needed, but generated code should be reviewed, tested, and understood before being considered complete.
